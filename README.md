## WareHouse Application
My Android WareHouse Application was developed to address the requirements of a small business. It included necessary fields such as: item, item type, expiration date etc.
This data was placed inside of a sqlite database since sqlite has a low impact on user device resources.
To develop and complete this application, I needed to integrate many concepts and designs. Concepts like user experience(UX) application logic, database management and testing.

the Most integral part of this project was the integration of the sqlite database. There were many things to consider when creating it. What fields am I storing.
What security measure do I need to instate. what is considered a bad field. This forced me to consider how data should be structured, accessed, updated and maintained inside this application.
I also had to balance this with the UX I designed as not to burden the user with too many security checks.

Unit Testing was equally important to this application as the database was. Unit Testing allowed me to not only check for expected behaviors, but unexpected ones as well.
Tests were made to insert valid values to the database and check if the result was correct. Tests were also created to insert bad values as well.
This allowed me to ask the simple question, would this catch errors such as conversion errors or a bad field being inserted. Over the long-term, testing becomes essential.
As we modify code, we often break old code. If I desire for my application to be easily maintained, then unit tests are the pillar of maintaining my application.

Finally, the project allowed me to gain experience in the separation of application responsibility. 
This allowed me to organize my code into objects and components that could be maintained and tested over the development-cycle of the application.
This allows for code that can be easily organized, maintained and adapted for future endeavors.
